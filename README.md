# Kalvoteq platform

Kalvoteq is a TanStack Start application with a public consultancy site, authenticated client portal, developer workspace, and admin workspace. Supabase provides authentication, PostgreSQL, and storage.

## Development

You need Node.js 22+ and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

For Hetzner deployment, see [deploy/README.md](deploy/README.md).

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
